# Electrical_Engineering_Assignment_Tracker README File Information

# App Name: Engineering Assignment Tracker 

# App Description: An application use to track assignments relating to Engineering students. This application will allow users to be able to edit their assignment list by being able to add, remove, view, or delete created tasks. Users can effortlessly keep track of their upcoming tasks and update their progress. Each registered account will have their own task list that is kept private.

# Application Functionality: Users can create an account using their email address in order to login and create their private task list. With this task list, users can add or delete existing tasks, edit their tasks with useful descriptions and set due dates to keep track of their progress. Each user will have their task list saved if they decide to logout of their account and then log back in. Every task list is kept private to each account.

# Setup Instructions:
# 1. Download the ZIP file from GitHub.
# 2. Extract the ZIP file to access folder with .html file.
# 3. Open the index.html file on a web browser.
# 4. Create or login to an account to access the application features.
